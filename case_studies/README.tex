\hypertarget{overlap-calculator-case-studies}{
\section{overlap-calculator Case
Studies}\label{overlap-calculator-case-studies}}

This directory contains 15 worked case studies, each isolating one
\textbf{user-selectable feature} of \texttt{overlap-calculator}. Case
studies 01--11 ship in three documentation formats --- Markdown, LaTeX
source, and a typeset PDF. Case studies 12--15 ship in Markdown and
LaTeX source (PDFs are built separately).

Each case study is intentionally small (\textbf{2 samples × 2 light
sources}) so a full run finishes in seconds and the repository stays
lean. The case isolates one knob at a time: light source, plot DPI,
broadening width, Beer--Lambert reference, wavelength grid, sheet
selection, etc.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{layout-shared-by-every-case}{
\subsection{Layout shared by every
case}\label{layout-shared-by-every-case}}

\begin{verbatim}
case_studies/<NN>_<name>/
+-- input.json
+-- submit.py
+-- README.md
+-- README.tex
+-- README.pdf
+-- output/
    +-- cli/
    |   +-- tables/{results,results_timings,descriptor_summary}.*
    |   +-- plots/...
    +-- api/
        +-- analysis_outputs.zip
        +-- tables/...
        +-- plots/...
\end{verbatim}

\texttt{input.json} is the 2-entry manifest that points at the bundled
files under
\href{https://github.com/pinarsyt/overlap-calculator/blob/main/input/files}{\texttt{../input/files/}}.
\texttt{submit.py} drives both the CLI and the HTTP API in one run. The
Markdown README is the narrative for the case; the LaTeX and PDF carry
the same content in typeset form. The \texttt{output/} tree is produced
once you run \texttt{submit.py}; case study 07 produces no
\texttt{plots/} directory because it turns plotting off.

\hypertarget{bundled-inputs}{
\subsection{Bundled inputs}\label{bundled-inputs}}

Every case study draws from the same files in
\href{https://github.com/pinarsyt/overlap-calculator/blob/main/input/files}{\texttt{../input/files/}}:

\begin{itemize}
\tightlist
\item
  13 Gaussian TD-DFT outputs (the case studies use 2 of them to keep
  runs short).
\item
  One PhotochemCAD-derived Excel workbook with 8 numeric absorbance
  series (the case studies use 2 of them).
\end{itemize}

\begin{quote}
\textbf{Citation for the experimental workbook.} The bundled
experimental absorbance data is derived from M. Taniguchi \& J. S.
Lindsey, "Database of absorption and fluorescence spectra of
\textgreater300 common compounds for use in PhotochemCAD",
\emph{Photochem. Photobiol.} \textbf{94} (2018) 290--327. See the
project
\href{https://github.com/pinarsyt/overlap-calculator/blob/main/README.md\#acknowledgement-of-third-party-data}{README}
for the full acknowledgement and BibTeX entries (covering both the
bundled light sources and the experimental workbook).
\end{quote}
